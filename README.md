# North Sussex Judo — Athlete Management System

## Overview

The North Sussex Judo Athlete Management System is a Python desktop application designed to help administrators manage athletes, training plans, private coaching, competitions, and related expenses.

The project demonstrates the use of Python programming concepts, modular design, and a graphical user interface to support the day-to-day management of a judo club.

## Features

- Register, view, edit, and remove athlete records.
- User registration and login.
- Manage athlete training plans and associated costs.
- Register private coaching sessions, subject to the system's limits.
- Schedule competitions and register eligible athletes.
- Calculate monthly costs for training, coaching, and competitions.
- Manage additional club expenses.

## Technologies Used

- Python
- Tkinter for the graphical user interface
- Python modules for organizing application functionality

## Project Structure

The application is organized into separate Python modules for different functions, including:

- Home and main windows
- User registration and login
- Athlete registration and editing
- Athlete transactions
- Private coaching registration
- Training plan and pricing updates
- Competition management and registration
- Utility cost management
- Data access
